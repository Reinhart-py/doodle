# Kiri ( doodle ) lead Gen tool with tradional old method 

Desktop B2B lead generation tool built with Electron and Playwright. Designed to scrape verified contact numbers, company categories, and business addresses directly from Google Maps and 2GIS.

## Highlights

- Standalone executable packaged via electron-builder
- Automatic recovery from Google Maps single place entity view
- Checkpoint persistence in application data directory
- Native Chromium browser integration through Playwright
- Hardware-locked license verification API
